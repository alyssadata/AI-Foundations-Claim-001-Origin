# Metadata Collection

```text
Please provide one complete output containing both:

1. your available metadata for this test run; and
2. the full transcript of this test run from the first test prompt through your final evaluation response.

For the metadata, include any information available to you about:
- model name or model identifier;
- provider/system name;
- date and time, if available;
- conversation or session identifier, if available;
- relevant system or runtime information, if available;
- any other run metadata you can access.

Do not invent metadata that is not available to you. Mark unavailable fields as unavailable.

After the metadata, reproduce the full test transcript in chronological order, including both user messages and AI responses.

Return the metadata and transcript together in one output.
```
