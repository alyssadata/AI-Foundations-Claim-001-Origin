# Metadata Collection

```text
Please provide one complete output containing both:

1. the metadata for this test run; and
2. the full transcript of this test run from the first test prompt through your final evaluation response.

Use the following run identifiers:
- Test: Test_001
- Run condition: baseline_run
- Case: state the case letter provided in the historical data you received

For the metadata, include as much information as is actually available to you, including:
- test identifier;
- run condition;
- case letter;
- model name;
- model identifier or model version, if available;
- model provider or system name;
- product, application, or interface through which the test is being run, if available;
- date;
- time;
- time zone, if available;
- conversation, chat, session, or run identifier, if available;
- model configuration or generation settings exposed to you, if available;
- reasoning mode or similar model mode, if explicitly available;
- tools, connectors, browsing, code execution, memory, or other runtime capabilities available during the run, if explicitly available;
- tools or capabilities actually used during the run, if available;
- relevant system, runtime, environment, build, or deployment information, if available;
- any other run metadata you can directly access.

Do not invent, infer, or guess metadata that is not available to you. Mark unavailable fields as unavailable.

After the metadata, reproduce the full test transcript in chronological order, including every user message and every AI response from the first Test_001 prompt through the final evaluation response. Preserve the wording as exactly as possible.

Return the metadata and transcript together in one output.
```
